# Security and Evidence Corrections

Report calculation-evidence errors or security concerns to `support@baziclarity.com`.

Please include:

- the public vector ID or document path;
- the observed and expected behavior;
- the software/runtime version used for verification;
- a minimal fictional reproduction when possible.

Do not send:

- real birth records;
- customer names or email addresses;
- order numbers or payment data;
- passwords, authentication codes, API keys, or private keys;
- private report files.

This repository does not provide personal BaZi consultation or emergency support.
